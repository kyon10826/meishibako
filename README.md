# めいしばこ 🐰

名刺をかわいく整理できる、ログイン不要の名刺箱アプリです。URLを開くだけで、誰でも自分の名刺箱として使えます。
ログインすると、グループのメンバーと名刺を共有して、みんなで追加・編集することもできます（任意。Firebase の設定が必要）。

公開URL：https://kyon10826.github.io/meishibako/

## 特徴

- 名刺の画像と、次の項目をこの順で登録できます：なまえ・コミュニティ・会社名・部署・役職・郵便番号・住所・電話番号・携帯電話番号・FAX・メールアドレス・SNS・重要度・名刺交換日・メモ（一覧・詳細・バックアップ・Excelも同じ順）
- 郵便番号は7けたの数字を入れると「123-4567」の形に整えます。名刺交換日は、新しく追加するときは今日の日付が入っています
- 重要度（💖〜💖💖💖、お店の名刺は ⭐️ おみせ）とカードの色で分けて、検索・並び替えができます
- 名刺の一覧を Excel ファイル（.xlsx）に書き出せます（画像は含みません）
- 名刺はその端末のブラウザの中（IndexedDB）だけに保存され、サーバーには送られません
- 一度開けばオフラインでも使えます。ホーム画面に追加するとアプリのように起動できます
- バックアップ（.json）の保存と読み込みで、機種変更や別の端末への引っ越しができます
- Claude 上の「めいしばこ」で保存したバックアップも、そのまま読み込めます
- （任意）グループを作って招待リンクを送ると、メンバー全員で名刺と画像を見たり、追加・編集・削除したりできます

## 使い方

1. ページを開き、右下の ＋ から名刺を追加します
2. ホーム画面に追加します
   - iPhone / iPad：Safari の共有ボタン → 「ホーム画面に追加」
   - Android / PC：画面下の「📲 アプリとして追加」（ブラウザのメニューからでも可）
3. ときどき「📦 バックアップ保存」をします。別の端末では「📂 バックアップ読み込み」で戻せます

ブラウザのデータを消したり、端末をなくしたりすると名刺も消えます。バックアップファイルは、クラウドのドライブなど端末の外に置いておくと安心です。

## グループで共有する（任意）

ヘッダーの「📱 この端末 ▾」から、名刺箱を切り替えます。

- **この端末だけ**：今までどおり。ログイン不要で、名刺はこの端末の中にだけ保存されます
- **グループ**：Google アカウントかメールアドレスでログインして使います。グループはいくつでも作れて、1人でいくつものグループに入れます
  - 招待：「⚙️ このグループのメンバーと招待」の招待リンクを送ります。開いた人がログインして「参加する」を押すと、メンバーになります
  - メンバー全員が、名刺と画像を見たり、追加・編集・削除したりできます。詳細画面に、だれが追加・更新したかが出ます
  - 別々の人が同じ名刺の別の項目を同時に直しても、両方の変更が残ります（同じ項目を同時に直したときは、あとから保存した方が残ります）
  - 圏外で追加・編集した分は、ネットにつながったときに自動で送られます
  - 作成者（👑）だけが、グループ名の変更・招待リンクの作り直し・メンバーを外す・グループの削除をできます。メンバーを外すと、招待リンクも自動で作り直されます
  - 「📱 → 👥 このグループにコピー」で、この端末の名刺をグループにコピーできます（端末の名刺はそのまま残ります）
- グループの名刺は、Google の Firebase（Cloud Firestore）に保存されます。名刺には取引先など**ほかの人の連絡先**が入るので、招待リンクは信頼できる人にだけ送ってください

### はじめの設定（アプリを公開する人が1回だけ）

`firebase-config.js` が `null` のあいだは、グループ機能は表示されず、今までどおり「この端末だけ」で動きます。

1. [Firebase コンソール](https://console.firebase.google.com/) で「プロジェクトを作成」（名前は例：`meishibako`。Google アナリティクスはオフでOK）。料金プランは無料の **Spark** のままで使えます
2. 「構築」→「Authentication」→「始める」→「ログイン方法（Sign-in method）」で、**メール / パスワード** と **Google** を有効にする
3. 「Authentication」→「設定」→「承認済みドメイン」→「ドメインを追加」で `kyon10826.github.io` を追加する
4. 「構築」→「Firestore Database」→「データベースを作成」→（エディションを聞かれたら **Standard**）→ ロケーションは `asia-northeast1`（東京）→ **本番環境モード** で作成
5. 「Firestore Database」→「ルール」タブに、このリポジトリの `firestore.rules` の中身をまるごと貼り付けて「公開」
6. 「プロジェクトの設定」（歯車）→「マイアプリ」→ ウェブ（`</>`）でアプリを登録（Firebase Hosting は不要）→ 表示される `firebaseConfig` の `apiKey`・`authDomain`・`projectId`・`appId` を、`firebase-config.js` の「例」の形で書いて push する
7. 数分後にアプリを開き直すと、ヘッダーに「📱 この端末 ▾」が出ます

`apiKey` などは公開されても問題ない値です（ブラウザに配られるものです）。データを守っているのは `firestore.rules` なので、`firestore.rules` を変えたときは手順5でもう一度貼り付けてください。

### 無料の範囲（Spark プラン）

- Cloud Firestore：保存 1 GiB まで、読み込み 5万回/日、書き込み 2万回/日、削除 2万回/日
- Authentication：ログインする人は1日 3,000人・1か月 5万人まで、新規登録は同じ回線から 1時間に100件まで
- 画像は Firestore に保存します（1枚ずつ約660KB以下に自動で縮めます）。Cloud Storage は有料プランが必要なため使っていません
- Spark プランには支払い情報がないので、超えても請求はされず、その日の分が止まるだけです（アプリには「無料の範囲を超えました」と出ます）
- 数字は変わることがあります。最新は [Firebase の料金ページ](https://firebase.google.com/pricing) を見てください

### うまくいかないとき

- 「このURLはログインが許可されていません」→ 手順3の承認済みドメインを確認
- 「保存する権限がありません」がずっと出る → 手順5のルールが「公開」されているか確認
- iPhone のホーム画面アプリで Google ログインが開かないときは、メールアドレスでログインするか、Safari で開いてください

## 公開のしかた（GitHub Pages）

1. GitHub で新しいリポジトリを Public で作ります（例：`meishibako`）
2. このフォルダの中身（`index.html`・`sw.js`・`manifest.webmanifest`・`icons/` など）を、フォルダ構成のままアップロードします
3. リポジトリの Settings → Pages を開き、Source を「Deploy from a branch」、Branch を `main` と `/(root)` にして Save します
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。このURLを共有すれば、誰でも使えます

リポジトリに入るのはアプリのプログラムだけです。「この端末だけ」の名刺は各自の端末に、グループの名刺は Firebase に保存され、どちらもリポジトリには入らないので、Public のリポジトリで問題ありません。

## 更新するとき

- `index.html` を差し替えて push すれば、利用者が次にネットにつながった状態で開いたときに反映されます
- アイコンなど `index.html` 以外のファイルを変えたときは、`sw.js` の `VERSION` の数字も上げてください
- 名刺データの保存形式（IndexedDB の構造やバックアップの形式）を変えるときは、古い形式も読めるようにしてください。グループの名刺も同じ形なので、知らない項目は消さずに残します
- Firebase のライブラリを新しくするときは、`vendor/` のファイル名の版数と、`index.html` の `FB_SDK` を一緒に変えてください

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（画面・保存・バックアップ・グループ） |
| `sw.js` | オフラインで開けるようにするための Service Worker |
| `firebase-config.js` | グループ機能の設定（Firebase のプロジェクト）。`null` ならグループ機能は出ない |
| `firestore.rules` | グループのデータを守るアクセスルール（Firebase コンソールに貼り付ける） |
| `vendor/firebase-13.0.0.js` | Firebase JavaScript SDK 13.0.0（Apache License 2.0、ライセンス表記はファイル末尾）。外部のCDNに頼らないよう同梱 |
| `manifest.webmanifest` | ホーム画面に追加したときの名前やアイコン |
| `icons/` | アイコン画像 |
| `.nojekyll` | GitHub Pages にファイルをそのまま配信させるための空ファイル |
